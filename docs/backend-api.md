# 脑护通 Demo 后端 API

后端与前端运行在同一个 Vinext 服务中，接口前缀为 `/api`。选项服务可通过 `AI_OPTIONS_MODE` 切换 Mock、固定兜底或 DeepSeek；置信度、选项签发、路径校验和任务状态规则始终由确定性代码执行。

DeepSeek 模式只允许模型调整审核候选项的顺序和短标签。模型不能新增意图、修改任务文案、风险等级或执行方式，调用失败时自动返回固定安全选项。

## 接口

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| `GET` | `/api/demo` | 获取任务、事件和置信度阈值 |
| `POST` | `/api/brain-control/evaluate` | 判定脑控输入是拒绝、需要确认还是接受 |
| `POST` | `/api/tasks` | 根据 1 到 3 层的完整确认路径创建护理任务 |
| `PATCH` | `/api/tasks/:id` | 接单、完成或记录转交申请 |
| `POST` | `/api/demo/reset` | 恢复演示种子数据 |

## 安全规则

- 置信度低于 `0.70`：拒绝。
- 置信度在 `0.70`（含）到 `0.85`（不含）之间：必须二次确认。
- 置信度不低于 `0.85`：接受。
- 任务状态只允许 `pending -> accepted -> done`。
- 整体置信度取已完成确认路径中的最低值，不代表医学诊断结论。

## 数据存储

当前 Demo 使用服务进程内存保存任务和审计事件，适合单机演示。关闭或重启服务后会恢复默认演示数据。生产实现应将存储替换为数据库，并增加身份认证、权限控制、并发控制和不可篡改审计。
